# ═══════════════════════════════════════════════════════════════
# Academy Manager Pro — نصب روی هاست بدون کامپایلر (cPanel فقط با
# دکمه‌ی «Run Pip Install» و بدون SSH/Terminal)
#
# چرا این فایل؟ «greenlet» یک افزونه‌ی C دارد و SQLAlchemy آن را به‌عنوان
# وابستگی می‌آورد. اگر wheel آماده پیدا نکند، pip آن را کامپایل می‌کند و
# روی هاستِ بدون کامپایلر با خطای زیر می‌شکند:
#
#     × Building wheel for greenlet (pyproject.toml) did not run successfully.
#
# خطِ `--only-binary=:all:` به pip می‌گوید «هرگز از سورس کامپایل نکن؛ فقط
# از wheel آماده نصب کن». همه‌ی پکیج‌های این پروژه برای پایتون ۳.۱۰ تا ۳.۱۳
# در معماری‌های رایج هاست (x86_64/amd64) wheel آماده دارند، بنابراین نصب
# بدون کامپایلر تمام می‌شود.
#
# در cPanel:
#   Setup Python App → اپلیکیشن → Configuration files → این فایل را Add کنید
#   → Run Pip Install → بدون Terminal نصب کامل می‌شود.
#
# اگر باز هم خطا گرفتید (مثلاً پایتون خیلی جدیدی انتخاب کرده‌اید):
#   python tools/install_deps.py --skip-greenlet
# (که در همین بسته برای هاست قرار دارد)
# ═══════════════════════════════════════════════════════════════
--only-binary=:all:
-r requirements.txt
