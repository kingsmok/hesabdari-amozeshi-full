مرحله ۱: نصب Python
═══════════════════

۱. به سایت https://python.org بروید
۲. Python 3.11 یا 3.12 را دانلود کنید
   (توصیه: از ۳.۱۴ استفاده نکنید مگر SQLAlchemy ۲.۰.۳۱ به بالا نصب باشد.
    پایتون ۳.۱۳/۳.۱۴ با SQLAlchemy قدیمی خطای TypingOnly می‌دهد.)
۳. هنگام نصب حتماً تیک "Add Python to PATH" را بزنید
۴. نصب را کامل کنید


مرحله ۲: دانلود نرم‌افزار
═══════════════════════════

پوشه academy_manager را در دسکتاپ کپی کنید


مرحله ۳: نصب پکیج‌ها
═══════════════════════

۱. روی پوشه academy_manager کلیک راست کنید
۲. "Open in Terminal" یا "Open PowerShell here" را بزنید
۳. این دستور را تایپ کنید (نسخه‌های دقیق و سازگار را نصب می‌کند):

   pip install -r requirements.txt --upgrade
   pip install PyQt6 PyQt6-WebEngine

   ⚠ نکته: نسخه SQLAlchemy باید ۲.۰.۳۱ به بالا باشد (در requirements.txt قفل شده است).
   اگر قبلاً برنامه را نصب کرده‌اید و هنگام اجرا خطای «TypingOnly» یا
   «__firstlineno__ / __static_attributes__» دیدید (معمول روی پایتون ۳.۱۳ و ۳.۱۴)،
   برنامه سعی می‌کند خودش SQLAlchemy را به‌روز کند. در غیر این صورت:

   python -m pip install --upgrade "SQLAlchemy>=2.0.31"

   سپس start_desktop.bat را دوباره اجرا کنید.

۴. Enter بزنید و صبر کنید تا نصب شود


مرحله ۴: اجرا
═══════════════

روش ۱ — دابل‌کلیک روی start.bat

روش ۲ — تایپ در ترمینال:
   python app_desktop.py

روش ۳ — اجرا با مرورگر:
   python app.py
   سپس در مرورگر: http://localhost:5000


مرحله ۵: ورود
═══════════════

نام کاربری: admin
رمز عبور:   **رمز حذف شده برای امنیت**


مرحله ۶: تنظیم شبکه (اختیاری)
══════════════════════════════

برای دسترسی از سایر کامپیوترها:

۱. آدرس IP خود را پیدا کنید:
   - در ترمینال تایپ کنید: ipconfig
   - آدرس IPv4 را یادداشت کنید (مثلاً 192.168.1.100)

۲. در سایر کامپیوترها مرورگر را باز کنید:
   http://192.168.1.100:5000

۳. اگر کار نکرد، فایروال ویندوز را چک کنید:
   - Control Panel → Windows Defender Firewall
   - Allow an app → Python را اضافه کنید


مرحله ۷: ساخت فایل نصب (اختیاری)
═══════════════════════════════════

برای ساخت فایل EXE:

۱. ابتدا PyInstaller را نصب کنید:
   pip install pyinstaller

۲. دستور زیر را اجرا کنید:
   build_exe.bat

۳. فایل AcademyManager.exe در پوشه dist ساخته می‌شود


تنظیم دیتابیس بزرگ (اختیاری)
══════════════════════════════

برای استفاده از PostgreSQL (مناسب داده‌های بزرگ):

۱. PostgreSQL را نصب کنید:
   https://www.postgresql.org/download/windows/

۲. درایور Python را نصب کنید:
   pip install psycopg2-binary

۳. از منوی نرم‌افزار: تنظیمات → دیتابیس
   نوع را PostgreSQL انتخاب کنید
   اطلاعات اتصال را وارد کنید


تنظیم ربات تلگرام (اختیاری)
═════════════════════════════

۱. به @BotFather در تلگرام پیام دهید
۲. /newbot بزنید و نام بات را وارد کنید
۳. توکن را کپی کنید
۴. از منو: پنل مدیریت → ربات تلگرام
   توکن را وارد کنید و ذخیره کنید


تنظیم فراز اس‌ام‌اس (اختیاری)
══════════════════════════════

۱. در farazsms.com ثبت‌نام کنید
۲. API Key بسازید
۳. از منو: پنل مدیریت → فراز اس‌ام‌اس
   کلید را وارد کنید
